קובץ התרגול: הקפיטריה של בית הספר

קובץ קטן ובדוי, רק לתרגול (לא הנתונים של הפרויקט שלכן). יש בו "בעיות" שהוכנסו בכוונה, כדי שיהיה מה לתקן. אל תתקנו אותן באקסל: כל התיקונים נעשים ב-Power BI.

  • Purchases: 42 קניות. כל שורה היא קנייה אחת: כיתה, מוצר, כמות, זמן המתנה בתור, שביעות רצון (1–5), אמצעי תשלום.
  • Items: 10 מוצרים, עם קטגוריה ומחיר בשקלים. זו טבלת העזר.

כרטיס 1 מתוך 8

ייבוא נתונים מאקסל

בשביל מה: להכניס קובץ אקסל ל-Power BI ולהחליט: לטעון כמו שהוא, או לנקות קודם.

👣 איך עושים
  1. Home › Get data › Excel workbook (או Import data from Excel במסך הפתיחה הריק), ובחרו את הקובץ.
  2. בחלון Navigator סמנו ✓ רק את הגיליונות שאתן צריכות. לחיצה על שם גיליון מציגה תצוגה מקדימה.
  3. Load טוען ישר למודל, בלי שינוי. Transform Data פותח את Power Query Editor כדי לנקות קודם. כשיש בנתונים בעיות, בוחרים Transform Data.
  4. ב-Power Query כל פעולה נרשמת ב-Applied Steps, כמו מתכון שאפשר לחזור עליו. בסיום: Home › Close & Apply.
  5. לבדיקה: Table view (סמל הטבלה בסרגל השמאלי) מציג את הנתונים שנטענו.

Power Query: הסרת כפילויות ועמודות

בשביל מה: לוודא שכל שורה היא רשומה אמיתית אחת, ולהשאיר רק את העמודות שצריך.

👣 איך עושים
  1. ב-Power Query Editor לחצו על כותרת עמודה כלשהי, ואז Ctrl+A כדי לבחור את כל העמודות.
  2. Home › Remove Rows › Remove Duplicates: נמחקות רק שורות שזהות בכל העמודות שנבחרו.
  3. ⚠️ בחרתן עמודה אחת בלבד? אז נשארת שורה אחת לכל ערך בעמודה הזו, וכל השאר נמחק. כמעט תמיד זו טעות.
  4. עמודות: בחרו עמודה (עם Ctrl אפשר כמה) ← Home › Remove Columns. או הפוך: Home › Choose Columns וסמנו רק את מה שנשאר.
  5. טעיתן? ב-Applied Steps לחצו על ✕ ליד הצעד, והוא נעלם.

Power Query: החלפת ערכים וניקוי טקסט

בשביל מה: לאחד ערכים שנכתבו בכמה צורות, כדי שכל קבוצה תיספר פעם אחת.

👣 איך עושים
  1. קודם רואים את הבעיה: החץ בכותרת העמודה מציג את כל הערכים השונים. אפשר גם View › Column distribution.
  2. רווחים מיותרים ותווים נסתרים: בחרו עמודה ← Transform › Format › Trim, ואחר כך Clean.
  3. אותיות גדולות וקטנות: Transform › Format › Capitalize Each Word.
  4. מה שנשאר: לחיצה ימנית על העמודה ← Replace Values. ב-Value To Find כותבים את הכתיב השגוי, וב-Replace With את הנכון. ב-Advanced options יש Match entire cell contents, כדי לא להחליף חלק ממילה.
  5. בודקים שוב בחץ של הכותרת שנשארו רק הערכים הנכונים.
למה דווקא ב-Power Query? בדוח עצמו Power BI לא מבחין בין אותיות גדולות לקטנות, אז grade 9 ו-Grade 9 עלולים להתאחד בגרף ולהסתיר את הבעיה. ב-Power Query רואים כל כתיב בנפרד.

כרטיס 4 מתוך 8

סוגי נתונים ומיון קטגוריות

בשביל מה: לוודא שמספר הוא מספר ותאריך הוא תאריך, ולסדר קטגוריות טקסט בסדר הגיוני ולא לפי א״ב.

👣 איך עושים
  1. הסמל בכותרת העמודה ב-Power Query מראה את הסוג: ABC טקסט, 123 מספר שלם, 1.2 עשרוני, 📅 תאריך. לחיצה על הסמל משנה את הסוג.
  2. הבעיה: טקסט ממוין לפי א״ב, אז 2-5 min מופיע לפני Under 2 min. הפתרון: עמודת סדר מספרית.
  3. Add Column › Conditional Column: קראו לעמודה WaitOrder. אם WaitTime שווה Under 2 min אז 1; ב-Add Clause הוסיפו 2-5 min ← 2, 5-10 min ← 3; וב-Else 4. שנו את סוג העמודה ל-Whole Number, ואז Close & Apply.
  4. ב-Table view לחצו על העמודה WaitTime ← Column tools › Sort by column ← WaitOrder.
  5. בגרף: ⋯ More options › Sort axis ← בחרו WaitTime ← Sort ascending. (בלי זה, גרף עמודות ממוין לפי הגובה של העמודות.)

קשר בין טבלאות (1 לרבים)

בשביל מה: לחבר טבלה ראשית לטבלת עזר, כדי להשתמש בעמודות של שתיהן באותו גרף (כמו XLOOKUP, רק קבוע).

👣 איך עושים
  1. עברו ל-Model view (הסמל השלישי בסרגל השמאלי). כל טבלה מופיעה שם כקופסה.
  2. גררו את ItemID מ-Items אל ItemID ב-Purchases. או: Home › Manage relationships › New.
  3. בחלון בדקו: Cardinality = One to many (1:*), ו-Cross filter direction = Single. צד ה-1 הוא הטבלה שבה כל מפתח מופיע פעם אחת.
  4. המפתח חייב להיות מאותו סוג בשתי הטבלאות (למשל Whole Number בשתיהן). אם לא, תקנו ב-Power Query.
  5. לפעמים Power BI יוצר קשר לבד. לחצו פעמיים על הקו ובדקו שהוא נכון.

כרטיס 6 מתוך 8

בחירת ויזואל: עמודות, פיזור, מטריצה

בשביל מה: לבחור גרף לפי השאלה: השוואה בין קבוצות, קשר בין שני משתנים, או התפלגות.

👣 איך עושים
  1. ב-Report view בחרו ויזואל בחלונית Visualizations, וגררו שדות מחלונית Data אל השדות שלו.
  2. השוואה בין קבוצות ← Clustered bar chart (אופקי, טוב לשמות ארוכים) או Clustered column chart.
  3. קשר בין שני מספרים ← Scatter chart: מספר אחד ב-X Axis, השני ב-Y Axis, ומה שכל נקודה מייצגת ב-Values.
  4. טבלה צולבת (כמו Pivot באקסל) ← Matrix: Rows, Columns, Values.
  5. התפלגות (כמה יש מכל ערך) ← עמודות של ספירה (Count). בכל שדה בערכים בדקו בחץ אם הוא Sum, Average או Count.

כרטיס 8 מתוך 8

עיצוב מותנה בטבלה ובמטריצה

בשביל מה: לצבוע תאים כך שהעין תמצא מיד את הגבוה והנמוך.

👣 איך עושים
  1. בחרו את הטבלה או המטריצה. ב-Visualizations, בשדה Values, לחצו על החץ שליד השדה (או לחיצה ימנית) ← Conditional formatting.
  2. Background color: ב-Format style בחרו Gradient, וצבע לערך הנמוך ולגבוה. אפשר גם Rules לטווחים.
  3. Data bars: פס בתוך התא, שאורכו לפי הערך.
  4. להסרה: אותו תפריט ← Remove conditional formatting.
  5. עיקרון: צבע אחד, משמעות אחת. אדום-ירוק על נתון שאינו "טוב/רע" מטעה.
